# Scabbard
Scabbard is a library mod used in cross multiloader development (Fabric, Forge & NeoForge) and is a required dependency for various projects such as Solemngrounds, Revelations of the Void & Slayer's Beasts. Features include:
- Registration utilities
- Biome Modifications (Add Spawns/Features)
- Wood Families
- Vanilla compatibility (Flammable, Flattenable & Strippable Blocks and Dispensible Items)
- Various Data Generation providers

This mod is intended to streamline my personal mod development and more features may be added when my other projects would benefit from extra utilities.
